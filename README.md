# Tradução de Python para C

Atividade da Unidade 2 — Programação em C.

## Sobre

Este repositório contém os programas da atividade de tradução de programas Python para a linguagem C.

## Programas

1. Idade a partir do ano de nascimento
2. Quociente e resto da divisão
3. Média de três notas
4. Conversão de Celsius para Fahrenheit
5. Área e perímetro de um retângulo
6. Área de um círculo
7. Conversão de segundos para horas, minutos e segundos
8. Decomposição de número de três dígitos
9. Verificação de número par e positivo
10. Código ASCII de um caractere

## Linguagem

- C
